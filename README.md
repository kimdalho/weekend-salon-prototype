# 주말살롱 — 원데이클래스 예약 앱 프로토타입

서버 없이 브라우저에서 동작하는 모바일 웹 프로토타입입니다. 포트폴리오용 샘플이며, 서비스·클래스·호스트·후기는 모두 가상입니다. 클래스 사진은 AI로 생성한 이미지입니다.

## 화면 흐름

1. 홈: 검색, 카테고리, 이번 주 인기 클래스, 마감 임박
2. 추천: 사진 카드를 넘기며 찜하기 / 넘기기 (터치·마우스 드래그, 버튼, 되돌리기)
3. 클래스 상세: 소개, 호스트, 후기
4. 예약: 날짜 → 시간(마감 시간 선택 불가) → 인원(남은 자리만큼) → 예약자 정보(휴대폰 번호 자동 하이픈·형식 검사) → 결제 금액
5. 예약 완료, 예약 내역, 찜 목록, 하단 탭

## 기술

HTML · CSS · JavaScript (프레임워크 없음), Pointer Events 기반 스와이프, 모바일 반응형. 화면은 `index.html` 하나, 사진은 `img/` 폴더에 있습니다.
