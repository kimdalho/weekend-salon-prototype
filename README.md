# 주말살롱 — 원데이클래스 매칭 프로토타입

서버 없이 브라우저에서 동작하는 모바일 웹 프로토타입입니다. 포트폴리오용 샘플이며, 서비스와 데이터는 모두 가상입니다.

## 화면 흐름

1. 시작
2. 관심사·요일·예산 선택 (2개 이상 선택해야 다음으로)
3. 카드 스와이프: 오른쪽은 찜, 왼쪽은 넘기기 (터치·마우스 드래그, 버튼)
4. 찜 완료 화면
5. 클래스 상세
6. 예약: 마감된 시간은 선택 불가, 인원에 따라 금액 계산, 휴대폰 번호 자동 하이픈과 형식 검사
7. 예약 완료 티켓
8. 찜 목록

## 기술

HTML · CSS · JavaScript (프레임워크 없음), Pointer Events 기반 스와이프, 모바일 반응형. 파일 하나(`index.html`)로 구성돼 있습니다.
